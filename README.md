# MacAegis

一个自己平时用 Mac 时顺手写的小工具。主要用来解决几个日常经常遇到的小麻烦：**在菜单栏一眼看清网络分流状态**、**开会投屏时一键把私密文件藏起来**，顺便**随手清一清开发缓存和卸载残留**。

100% 用原生 Swift 写的，体积只有 3.5MB，内存占用大概 20 多兆，随开随用，没有任何后台常驻进程，也不收费。

---

## 💡 它能帮你做什么？

### 1. 菜单栏看网速 & 代理分流状态
平时挂着代理工具，经常不知道当前网页或终端到底是走直连还是走代理：
* 直接在 macOS 顶部菜单栏显示实时上传/下载速度；
* 旁边带一个小圆点：
  * 🔵 **蓝色**：普通直连（没走代理）
  * 🟢 **绿色**：规则分流（智能分流中）
  * 🔴 **红色**：全局代理
* 直接读取系统网络层状态，不用管你用的是什么代理客户端。

### 2. 私密文件/文件夹随手隐藏（防投屏尴尬）
开会投屏、外接显示器或者把电脑借给同事时，桌面或访达里的私密文档、私人照片容易被看到：
* 把文件或文件夹直接拖进保险箱，瞬间在访达里消失；
* 空格键快速预览也看不了；
* 采用原地处理，100GB 的大视频也是秒藏，不用傻傻等文件复制；
* 想看的时候按一下 Touch ID 指纹或者输密码，立刻在访达中自动跳出来；
* 即使以后不小心删掉了这个 App，重新装上也能通过钥匙串识别认领，文件不会丢。

### 3. 随手清理与干净卸载
* 顺手扫描 Xcode 构建缓存（DerivedData）、开发临时文件、日常日志和浏览器缓存；
* 把不需要的 `.app` 拖进来，自动找出 `~/Library` 里散落的关联配置文件一起清干净；
* 不像很多动辄几百兆的清理软件，MacAegis 平时不占 CPU，用完即关。

## 🛠️ 安装与运行

* **支持系统**：macOS 14.0 (Sonoma) 及以上版本
* **支持架构**：Apple Silicon (M1/M2/M3/M4) 及 Intel 芯片 Mac
* **开箱即用**：直接下载 Release 中的二进制或自己本地编译均可。

```bash
# 本地编译运行
git clone https://github.com/meowvia/MacAegis.git
cd MacAegis
swift build -c release
.build/arm64-apple-macosx/release/MacAegisApp
```
